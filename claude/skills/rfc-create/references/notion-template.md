# Notion RFC template — verbatim snapshot

Fetched 2026-08-05 from the team's Notion RFC page via `ntn pages get`. Kept as the
authoritative record of **section names and their order**. SKILL.md's template block is
derived from this; if the two ever disagree, this file is the source of truth for structure.

Reading notes, so nothing here is mistaken for RFC content:

- The YAML block below is **Notion page properties** (Squad, Authors, Status, …), not part of
  the RFC. Don't reproduce it. `name: MCP Refactor (RFC)` is the title of the page this
  template was captured from, not a title to copy.
- `{toggle="true"}` marks a collapsible Notion block. It carries no meaning in Markdown output.
- `<empty-block/>`, empty `<tr>` rows, and bare `-` / `1.` markers are unfilled placeholders.
- `\*` on a heading marks a **required** section: Executive Summary, Associated Links &
  Alternative Approaches, Implementation Plan, and Key Decisions.
- `### Milestone 1 (cycle est.)` confirms cycle estimates are part of the template, not optional.
- The template has **Terminology**, not "Domain Model", and orders Design criteria and
  Alternatives **before** Motivation & Business Case.
